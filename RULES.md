# DESIGN RULES

Le site doit être :
- ultra premium
- minimaliste
- cinématique
- très fluide
- élégant
- sophistiqué

# ANIMATIONS

- animations lentes
- easing naturel
- jamais cheap
- jamais cartoon
- transitions fluides
- priorité au scroll storytelling

# TYPOGRAPHIE

- grande
- contrastée
- beaucoup d’espace vide
- hiérarchie claire

# 3D

- subtile
- immersive
- jamais gadget
- priorité à l’élégance

# INTERDICTIONS

- pas de design bootstrap
- pas de cards génériques
- pas de glow excessif
- pas de gradients IA génériques
- pas de composants répétitifs

# OBJECTIF

Le site doit sembler conçu par une agence créative senior.
